# Frontend

## Authority Notice

The authoritative MVP frontend and backend implementation structure is defined in [../engineering/MVP-Application-Architecture.md](../engineering/MVP-Application-Architecture.md). This document remains a high-level overview.

## Purpose
The frontend provides the public website and the authenticated trading experience.

## Users
- visitors exploring the product
- traders using the application workspace

## Features
- marketing and product content
- dashboard and workspace surfaces
- research and analysis views
- theme support

## Future ideas
- reusable module shells
- richer data visualizations
- improved navigation patterns

## Dependencies
- Next.js
- React
- TypeScript
- Tailwind CSS

## Open Questions
- User-created dashboards and a grid-layout library remain deferred.
- Later modules must follow the approved route, feature, widget, and Server/Client Component boundaries.
